## 一、业务目标理解

### 1.1 核心业务目标

管理员（admin）通过后台管理系统完成平台运营维护，涵盖 6 个主流程：

| 序号 | 主流程 | 业务目标 |
|------|--------|---------|
| 1 | 仪表盘（数据概览） | 查看平台运营数据总览 |
| 2 | 商品管理 | 新增、编辑、上下架商品 |
| 3 | 分类管理 | 新增、编辑、删除商品分类 |
| 4 | 订单管理 | 查看、搜索、筛选订单，执行状态操作 |
| 5 | 用户管理 | 查看、搜索用户，禁用/启用用户 |
| 6 | 评价管理 | 查看、删除评价 |

### 1.2 涉及角色

| 角色 | 用户名 | 权限范围 | 来源 |
|------|--------|---------|------|
| 管理员 | admin | 后台管理全部权限 | F-29~F-34 |
| 普通用户 | buyer1/buyer2 | 不可访问后台（重定向到首页） | F-27 |

## 二、关键业务规则

### 2.1 商品管理规则

- **新增商品**：弹窗表单，字段含名称、描述、分类、基础价格、基础原价、基础库存、状态（上架/下架）、商品图片（至少1张最多6张）、规格组（可选）
- **编辑商品**：弹窗表单预填当前数据，修改后保存
- **上下架**：操作按钮在"编辑"旁，状态在"上架"与"下架"之间切换

**追溯：** 业务梳理 §2.2（F-30）

### 2.2 分类管理规则

- 分类列表含：ID、图标、分类名称、排序、操作
- 操作列：每行有"编辑""删除"按钮
- 当前6条分类数据

**追溯：** 业务梳理 §2.3（F-31）

### 2.3 订单管理规则

- 订单列表含：订单号、用户、金额、商品、状态、下单时间、操作
- 支持搜索订单号和状态筛选
- **🔴 高危异常 S-02：所有订单的操作列为空，管理员无法执行任何操作**
- 订单状态机真实 API 端点（服务端源码验证）：
  - 创建订单：`POST /api/orders`（需 addressId，Joi 必填）
  - 待支付→已支付：`POST /api/orders/:id/pay`
  - 已支付→已发货：`PUT /api/admin/orders/:id/ship`
  - 已发货→已完成：`PUT /api/orders/:id/confirm`
  - →已退款：`PUT /api/admin/orders/:id/refund`

**追溯：** 业务梳理 §2.4（F-32）

### 2.4 用户管理规则

- 用户列表含：ID、用户名、昵称、邮箱、手机号、角色、状态、注册时间、操作
- admin 行无操作按钮（不能禁用自己）
- buyer1/buyer2 行有"禁用"按钮；disabled_user 行有"启用"按钮

**追溯：** 业务梳理 §2.5（F-33）

### 2.5 评价管理规则

- 评价列表含：ID、用户、商品、评分、评价内容、评价时间、操作
- 操作列：每行有"删除"按钮

**追溯：** 业务梳理 §2.6（F-34）

## 三、风险识别（8 维度核对）

### 3.1 正向维度

| 风险点 | 描述 | 优先级 |
|--------|------|--------|
| 新增商品完整流程 | 弹窗表单填写→保存→列表刷新 | PO |
| 编辑商品完整流程 | 弹窗表单预填→修改→保存→列表刷新 | PO |
| 上下架商品 | 状态切换→前台可见性联动 | PO |
| 新增/编辑/删除分类 | 分类 CRUD 完整性 | PO |
| 用户禁用/启用 | 状态切换→登录权限联动 | PO |
| 评价删除 | 删除操作→前台评价消失 | PO |
| 仪表盘数据展示 | 统计卡片数据准确性 | P2 |

### 3.2 异常维度

| 风险点 | 描述 | 优先级 |
|--------|------|--------|
| 🔴 订单管理操作列为空 | 管理员无法执行发货等操作（S-02） | PO |
| 新增商品必填字段为空保存 | 表单校验机制（Q-03） | PO |
| 编辑商品保存后数据不一致 | 列表刷新与数据同步（B-A03） | P1 |
| 删除有商品关联的分类 | 数据关联完整性（Q-04, B-S03） | PO |
| 下架操作无确认弹窗 | 误操作风险（Q-05, B-A05） | P1 |
| 评价删除无确认弹窗 | 误操作风险（Q-08） | P1 |

### 3.3 边界维度

| 风险点 | 描述 | 优先级 |
|--------|------|--------|
| 商品名称最大长度 | 必填字段长度边界 | P1 |
| 商品价格边界 | 最小值/负数/小数精度 | P1 |
| 商品库存边界 | 最小值/负数/整数 | P1 |
| 商品图片数量边界 | 至少1张最多6张 | P1 |
| 分类名称最大长度 | 必填字段长度边界 | P2 |
| 大量规格组合 | 规格组合数 = 各组值数量的乘积 | P2 |

### 3.4 权限维度

| 风险点 | 描述 | 优先级 |
|--------|------|--------|
| 管理员访问后台 | admin 可正常访问所有后台页面 | PO |
| 普通用户访问后台 | buyer1 访问 /admin 被重定向 | PO |
| 未登录访问后台 | 直接访问后台 URL 的拦截 | PO |
| 管理员自保护 | admin 行无禁用按钮 | P1 |
| 禁用用户访问后台 | disabled_user 无法登录，间接无法访问 | P1 |

### 3.5 状态维度

| 风险点 | 描述 | 优先级 |
|--------|------|--------|
| 商品状态切换 | 上架↔下架，操作按钮随之变化 | PO |
| 用户状态切换 | 正常↔禁用，操作按钮随之变化 | PO |
| 订单状态操作 | 后台对不同状态订单的操作（S-02 阻断，真实 API 端点已验证） | PO |
| 分类删除后商品状态 | 分类删除对关联商品的影响 | P1 |

### 3.6 配置维度

| 风险点 | 描述 | 优先级 |
|--------|------|--------|
| 后台分页大小 | 10条/页（与前台12条/页不同） | P3 |
| 后台菜单结构 | 6项菜单完整性 | P3 |

### 3.7 数据一致性维度

| 风险点 | 描述 | 优先级 |
|--------|------|--------|
| 🔴 后台订单操作列为空 | API 造已支付订单后查操作列 | PO |
| 新增商品后前台可见性 | 后台新增→前台列表同步 | PO |
| 编辑商品后前台数据同步 | 后台编辑→前台详情同步 | P1 |
| 下架商品后前台不可见 | 后台下架→前台搜索/列表同步 | PO |
| 删除评价后前台消失 | 后台删除→前台评价区同步 | PO |
| 禁用用户后无法登录 | 后台禁用→前台登录拦截 | PO |
| 分类删除后商品数据 | 删除分类→商品分类字段处理 | P1 |

### 3.8 网络与加载异常维度

| 风险点 | 描述 | 优先级 |
|--------|------|--------|
| 保存商品时网络中断 | 数据丢失或部分保存 | P3 |
| 重复点击上下架按钮 | 状态不一致 | P2 |
| 重复点击删除评价按钮 | 重复删除 | P2 |

## 四、测试策略说明

### 4.1 PO 级用例（必须通过）

本轮必须验证以下核心场景：

1. **🔴 后台订单操作列为空的复现**
   - 通过真实 API 端点创建"已支付"状态订单（`POST /api/orders` + `POST /api/orders/:id/pay`）
   - 在后台订单管理页面查看操作列是否有按钮
   - 追溯：业务梳理 §2.4（F-32, S-02, Q-02）

2. **核心 CRUD 保存/确认响应**
   - 新增商品：填写表单→保存→验证列表刷新和前台可见
   - 编辑商品：修改字段→保存→验证数据更新
   - 分类新增/编辑/删除：验证确认弹窗和数据变化
   - 用户禁用/启用：验证状态切换和登录权限联动
   - 评价删除：验证确认弹窗和前台同步
   - 追溯：业务梳理 §2.2~2.6

3. **商品上下架状态切换**
   - 验证上下架操作的确认弹窗（Q-05）
   - 验证前台商品可见性联动

4. **权限隔离验证**
   - 未登录访问后台
   - 普通用户访问各后台子路径

### 4.2 测试数据策略

- **本轮新建测试数据**，不修改种子数据
- 新增商品：通过后台"新增商品"创建测试专用商品
- 新增分类：通过后台"新增分类"创建测试专用分类
- 订单状态：通过真实 API 端点迁移订单状态（`POST /api/orders/:id/pay`、`PUT /api/admin/orders/:id/ship` 等）
- 每条用例明确清理责任

### 4.3 探索性场景标注

以下场景因缺乏已验证事实支持，标记为探索性场景：
- 下架操作是否有确认弹窗（Q-05, candidate）
- 评价删除是否有确认弹窗（Q-08, blocked）
- 是否存在"删除商品"功能（Q-06, blocked）
- 编辑商品中删除规格组/规格值后的联动（Q-07, blocked）
