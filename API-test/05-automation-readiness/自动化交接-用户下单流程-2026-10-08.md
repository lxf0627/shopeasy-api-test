## 4. 数据链规格

### 4.1 动态字段提取

| 字段 | 来源响应 | 提取路径 | 类型 | 用途 |
|------|----------|----------|------|------|
| token | POST /api/auth/login | body.data.token | string | 认证凭证 |
| user_id | POST /api/auth/login | body.data.user.id | integer | 用户标识 |
| sku_id | GET /api/products/:id | body.data.skus[0].id | integer | SKU选择 |
| sku_price | GET /api/products/:id | body.data.skus[0].price | number | 价格验证 |
| address_id | GET /api/addresses | body.data[0].id | integer | 订单创建 |
| order_id | POST /api/orders | body.data.id | integer | 订单操作 |
| order_no | POST /api/orders | body.data.orderNo | string | 订单号 |
| stock | GET /api/products/:id | body.data.stock | integer | 库存验证 |

### 4.2 数据生命周期

| 数据 | 创建 | 使用 | 清理 |
|------|------|------|------|
| token | 登录接口 | 所有需认证接口 | 无需清理（自动过期） |
| 购物车项 | 添加购物车 | 创建订单 | 创建订单时自动清空 |
| 订单 | 创建订单 | 支付/发货/确认 | 取消或完成后保留 |

### 4.3 清理策略

- **成功场景**：订单数据保留，不清理
- **失败场景**：如创建订单失败，需手动清空购物车
- **库存测试**：测试完成后取消订单恢复库存
